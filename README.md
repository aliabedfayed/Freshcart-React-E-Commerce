# 🛒 E-Commerce React Application

A modern **E-Commerce Frontend Application** built with **React** focusing on clean architecture, proper state management, and real-world best practices.

---

## 🚀 Live Features

* Authentication (Login / Register)
* Products listing with search
* Product details with image slider
* Categories & Brands pages
* Category-based products
* Shopping cart (Add / Remove / Update / Clear)
* Online checkout (Stripe session redirect)
* Responsive UI

---

## 🛠️ Tech Stack

* **React**
* **Redux Toolkit**
* **React Query**
* **Axios**
* **React Router DOM**
* **Formik**
* **React Slick** (Sliders)
* **Tailwind CSS**
* **React Hot Toast**
